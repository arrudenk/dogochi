# dogochi

Тамагочі для **реального** пса. iOS + Android, Expo (React Native + TypeScript).

Це трекер догляду за конкретним псом — **Балу**, 4 роки, чорний як ніч, тип бігового віппета — переодягнений у стару RPG. Гейміфікація тут не самоціль: RPG-механіки виявились механічно точними для задачі.

Обробка від кліщів дає захист на 30 днів — це буквально **баф з таймером**. Огляд у лікаря раз на пів року — **обряд**. Виїзд у ліс — **похід**. Іконка оберега з полоскою, що тане, несе ту саму інформацію, що й запис у календарі, але її *видно*, а не читаєш.

## Стан

**v1 написана й збирається під обидві платформи.** 122 тести, типи чисті, бандл ~2.3 МБ на платформу.

Не зроблено свідомо: спайк пікселізації на **реальному фото Балу** (потрібні фото — силует збоку при денному світлі та портрет), збірка на пристрої через EAS, річний підсумок у хроніці, платні асет-паки чрому.

## Апка

```bash
cd app
npm install
npx expo start          # Expo Go на телефоні
npm test                # 122 тести чистих модулів
npm run typecheck
npx eas build -p all --profile preview   # збірка на пристрій
```

| Модуль | Відповідальність |
|---|---|
| `app/src/core` | **чистий двигун.** Журнал подій → обчислюваний стан. Нічого не імпортує, `now` приходить аргументом — це стереже тест |
| `app/src/store` | `expo-sqlite`, append-only журнал, модель під майбутній синк |
| `app/src/ui` | екрани й піксельний чром, без доступу до бази чи двигуна |
| `app/src/pixel` | конвеєр пікселізації + архетипні спрайти сайтхаунда |
| `app/src/shell` | звʼязка, нотифікації, календарна страховка |

Стек змінено зі Swift на Expo після затвердження дизайну — причини й наслідки в [§18 спеки](docs/superpowers/specs/2026-08-20-balu-design.md).

## Ключові рішення

- **Журнал подій + обчислюваний стан.** Зберігаються тільки незмінні факти. Рівень, XP, оберіги, статі, трофеї ніде не лежать — вони обчислюються з журналу. Тому дописування минулим числом працює саме собою, трофеї працюють ретроспективно, а синк потім зливається без конфліктів.
- **Стеля 999 вбудовує сенс апки.** Ідеальні щоденні тапи цілий рік дають рівень **427 і все**. Наблизитись до 999 без оглядів, обробок і походів у ліс фізично неможливо. Це захищено тестом.
- **Нагадування — не пуші, а діалог при вході.** Пуш приходить, коли ти не готовий діяти, і згорає. Пуш лишається тільки як **детектор тишини**: не заходив 3+ дні й щось насідає → чорний гончак виє на локскріні. Заходиш регулярно — не побачиш жодного ніколи.
- **Ніщо не карає.** Пропущене не забирає XP, рівень математично не може впасти. Просідає стат, ніколи не пес — ніяких сумних мордочок і «Балу голодний».
- **Пес малюється з фото.** Онбординг — це перший квест: пʼять знімків Балу пікселізуються в спрайти на пристрої, через маску обʼєкта Vision.

## Ліцензія

**Усі права застережено.** Це свідомий вибір, а не забутий файл: код і дизайн-документи цього репозиторію не ліцензовані для використання, модифікації чи розповсюдження. Публічність тут — для зручності роботи й прозорості процесу, не запрошення форкати.

Асети ведуться окремо в [`ASSETS.md`](ASSETS.md), з правилом: жоден сторонній асет не комітиться, поки в реєстрі нема рядка з його ліцензією. Чром інтерфейсу планується з [Kenney.nl](https://kenney.nl/assets) (CC0), спрайт пса — власний, з фото.
