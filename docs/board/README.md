# Дошки проєкту

Три борди для [freeboard](https://arrudenk.github.io/freeboard/) — інфініт-канвасу з JSON-бриджем.

## Файли

| Джерело правди | → | Борд для канваса |
|---|---|---|
| `balu-tasks.json` | | `balu-board.json` |
| `balu-refs.json` | | `balu-refs-board.json` |
| `balu-mechanics.json` | | `balu-mechanics-board.json` |

`build-boards.mjs` генерує всі три однією функцією розкладки. **`*-board.json` руками не редагувати** — вони перезаписуються.

```bash
node docs/board/build-boards.mjs
```

Генератор **падає з помилкою**, якщо дві ноди отримали однаковий x/y, замість того щоб дати імпортеру тихо розсунути їх на +24/+24 і зламати розкладку.

## Чому задачі через генератор, а решта теж

Статуси задач міняються часто — там генератор обовʼязковий, бо 55 нод з координатами руками розʼїдуться на третьому оновленні. Референси й механіки статичні, але розкладка в них та сама, тому дешевше було віддати їх тій самій функції, ніж тримати три різні підходи.

## Статуси задач

| Статус | Глиф | Колір ноди |
|---|---|---|
| `todo` | `▢` | білий |
| `doing` | `◐` | `#FFBE98` Peach Fuzz |
| `done` | `▣` | `#88B04B` Greenery |
| `blocked` | `⊘` | `#939597` Ultimate Gray |

Глиф дублює колір, бо PDF-експорт борду може піти чорно-білим.

**Колір секції = важливість** за палітрою Pantone Colors of the Year (за зростанням). Ф0 «Спайк» — Tangerine Tango, бо найризикованіше і йде першим.

## Як відкриваються

```
https://arrudenk.github.io/freeboard/?board=<raw-url-до-json>&mode=replace|add
```

`mode` за замовчуванням `replace`. Завантаження йде через історію канваса, тому ⌘Z повертає попередній борд, якщо лінка перезаписала не те.

Готові посилання — в [README проєкту](../../README.md).

## Структура

Напрям edge = ієрархія, тому `root → секція → картка`. Згортання секції ховає всі її картки, згортання `root` — весь борд. Прогрес і легенда підвішені до `root`, щоб не лишались сиротами (правило «no orphans» з `AI_GUIDE.md`).

## Обмеження

Санітайзер канваса не пропускає тег `<a>`, тому **посилання в нодах не клікабельні** — URL-и лежать текстом, щоб копіювались.
