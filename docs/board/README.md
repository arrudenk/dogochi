# Дошка проєкту

Візуальна мапа задач для [freedomOfThought](/Users/tomrude/Documents/freedomOfThought) — інфініт-канвас з JSON-бриджем.

## Файли

| Файл | Роль |
|---|---|
| `balu-tasks.json` | **джерело правди.** Фази, задачі, статуси. Редагується руками або мною по ходу роботи |
| `build-board.mjs` | генератор: розкладає задачі по сітці, рахує прогрес, малює легенду |
| `balu-board.json` | **результат.** Це те, що імпортується в канвас. Не редагувати руками |

## Оновити дошку

```bash
node docs/board/build-board.mjs
```

Далі в freedomOfThought: **Import JSON** (replace). Координати лежать у файлі, тому розкладка відтворюється однаково.

`Add JSON` (merge-upsert за `id`) теж працює, але оновить і позиції — тобто ручне перетасування нод все одно перезапишеться. Якщо перекладеш борд під себе і захочеш це зберегти — скажи, зафіксую нову розкладку в генераторі.

## Статуси

Задача має один з чотирьох статусів у `balu-tasks.json`:

| Статус | Глиф | Колір ноди |
|---|---|---|
| `todo` | `▢` | білий |
| `doing` | `◐` | `#FFBE98` Peach Fuzz |
| `done` | `▣` | `#88B04B` Greenery |
| `blocked` | `⊘` | `#939597` Ultimate Gray |

Глиф дублює колір, бо в PDF-експорті борд може піти чорно-білим.

**Колір фази = важливість** за палітрою Pantone Colors of the Year (за зростанням). Ф0 «Спайк» — Tangerine Tango, бо це найризикованіше і йде першим.

## Структура

Напрям edge = ієрархія, тому `root → фаза → задача`. Згортання ноди фази ховає всі її задачі; згортання `root` — весь борд. Прогрес і легенда підвішені до `root`, щоб не лишались сиротами.
